# Phase 187: 受害机接收口的双路耦合直接测量 — SIR = 16.0 dB（2026-09-17）

**类型：表征测量（非 A/B）** — 用受害机自己的 IQ 直接测出两条路径的绝对接收功率，
得出本系统最关键的未测量数字：**箱 A 自己的发射机，在箱 A 的接收机处，比箱 B 强多少**。

此前 P179–P184 全部结论都建立在"这个比值 >31.5 dB"的**推断**上。本 phase 推翻了该推断。

## VERDICT（逐字粘贴原始输出）

命令：`python3 p187_coupling_measure.py`（受害机 = 箱 192.168.10.2 / B:0，
tx-gain 31.5、rx-gain 31.5、rx-scale 40；两台发射机都用 MCS0 len38 / 100ms，
**占空比相同 → 比值与占空比无关**）

```
[P187] mean |x|^2  A = 1.526241e+00     <- A 发（B 静默）
[P187] mean |x|^2  B = 3.915558e-02     <- B 发（A 的 TX 关闭）
[P187] mean |x|^2  N = 1.298608e-02     <- 双方静默
[P187] wanted  path power (A->A) = 1.513255e+00
[P187] neighbor path power (B->A) = 2.616950e-02
[P187] SIR at victim RX = 17.62 dB   (capture threshold in P178 offline: ~+3 dB)
[P187] => headroom above threshold = 14.62 dB
```

## 关键修正：那个 "N" 不是本底，是 A 自己的 TX 泄漏

run3"双方静默"里 **A 的 tx-gain 仍是 31.5**（只把 tx-scale 压到 1e-5）——
**A 的 TX 链在满增益下的泄漏**被当成了噪声底。独立测底验证：

```
=== 本底噪声 vs TX 增益 & A 在 gain0 的实际信号 ===
  floor_gain31_scale0        (tx-gain  31.5, scale 1e-05)  |x|^2 = 1.3864e-02
  floor_gain0_scale0         (tx-gain     0, scale 1e-05)  |x|^2 = 9.0071e-04
  A_signal_at_gain0          (tx-gain     0, scale 1)      |x|^2 = 1.9087e-03

本底差（TX gain 31.5 vs 0）: +11.87 dB  -> TX 泄漏主导
```

**真本底比 run3 测到的低 11.87 dB**（1.3864e-02 → 9.0071e-04，15.4×）。
用真本底重算：

| 量 | 值 |
|---|---|
| A 路径功率 = 1.526241 − 9.0071e-04 | 1.52534 |
| B 路径功率 = 3.915558e-02 − 9.0071e-04 | 3.82549e-02 |
| **SIR = 10log₁₀(1.52534 / 3.82549e-02)** | **16.01 dB** |

**判定：SIR = 16.0 dB**（直接测量的收紧值；17.62 dB 是未扣 TX 泄漏的上界）。

## 副产品 1：tx-gain 旋钮是线性的（满量程 31.4 dB，标称 31.5 dB）

A→A 自链路接收功率 vs A 的 tx-gain（B 静默，tx-scale 1.0）：

```
  tx-gain   31.5  |x|^2 = 1.4911e+00
  tx-gain     24  |x|^2 = 2.7943e-01
  tx-gain     16  |x|^2 = 4.2122e-02
  tx-gain      8  |x|^2 = 8.1816e-03
  tx-gain      4  |x|^2 = 3.5867e-03
  tx-gain      0  |x|^2 = 1.9772e-03
```

满量程 31.5→0：10log₁₀(1.4911/1.9772e-03) = **−28.77 dB**（表观）。
扣掉 gain-0 点里的本底（1.9772e-3 − 9.0071e-4 = 1.0765e-3）后 =
10log₁₀(1.4911/1.0765e-3) = **−31.41 dB vs 标称 −31.5 dB**。

**结论：旋钮线性，偏差 ≤0.1 dB。** 不扣本底会在低增益端系统性低估动态范围 2.6 dB。

## 副产品 2：平均 |x|² 是占空比平均量——不要用它推"链路信噪比"

`mean |x|²` 覆盖整个捕获窗，其中 99.88% 的时间没有帧。所以：

- A 在 gain 0 时平均 |x|² = 1.9772e-03，扣本底后 1.0765e-03，看似只有 **+3.3 dB**
  （`A 在 gain0 的信号 vs 真本底: +3.26 dB`）——**这个数会误导**：
  帧占空比 0.12%，同值意味着**帧内**瞬时功率 ≈ 1.0765e-3 / 0.0012 ≈ 0.90，
  即**帧内 SNR ≈ +30 dB**。
- 因此 P180 实测的"A 在 gain 0 仍有 52%"**不是 3 dB 信噪比下解码**，
  而是帧内 30 dB 信噪比下的正常链路。

**方法论：跨占空比比较平均功率无意义；同占空比的比值（本 phase 的 SIR）才有效。**

## 对 P179–P184 的勘误（据本 phase 更正）

**被推翻的推断**：P180 曾从"把 A 降 31.5 dB 仍看不见 B 的干扰"推出
**"SIR > 31.5 dB"**，并据此提出"同箱近场耦合主导 SIR，Tx 增益轴无杠杆"。

**实测 SIR = 16.0 dB，比该推断低 15.5 dB。** 该推断失效的原因现已明确：

1. **P180 的 A 在 gain 0 时 SIR 已是 −15.5 dB**（跨过 +3 dB 捕获门限 18.5 dB），
   **干扰条件早就满足了** —— 不是"没有干扰"，而是
2. **B 当时的帧占空比只有 0.12%**（len38 / 100ms），B 的帧与 A 的帧
   时间重合的概率约 0.12%。**看不见的效应不等于不存在的效应。**

这与 P182 的独立发现一致（占空比 0.12% → 0pp；13% → −16pp；26% → −88pp）。

⚠️ **待办**：P179/P179b/P180 的 verdict 里"同箱近场耦合压倒性占优 / SIR >31.5 dB"
一类表述应据本 phase 标注为**已被直接测量推翻**（SIR = 16.0 dB）。

## SIR 随 A 增益的预测式（供 P188 使用）

旋钮线性 + B 路径固定 ⇒ **SIR(A_gain) = A_gain − 15.5 dB**：

| A tx-gain | 31.5 | 24 | **18.5** | 12 | 6 | 0 |
|---|---|---|---|---|---|---|
| SIR at A 的 RX | 16.0 | 8.5 | **+3.0** | −3.5 | −9.5 | −15.5 |

**在 A ≈ 18.5 dB 处跨过 P178 离线预测的 +3 dB 捕获门限。**
P188 的实验正是扫这条轴。

## 机制与实现

- 新脚本 `p187_coupling_measure.py`：三次捕获（A 发 / B 发 / 双方静默），
  在受害机 IQ 上取 `mean |x|²`，扣本底后取比值
- **踩过的坑（已修）**：run2 传 `SILENT_SCALE` 会把 **B** 衰减掉
  （因为 harness 的 `--tx-addr` 指向 B），量到的是噪声。A 在 run2 天然静默
  （它不是 TX 目标），正确做法是传 `1.0`
- 本 phase 改动全在新编排脚本，**harness 与 `lib/` 零改动** → 未做 loopback 回归门
