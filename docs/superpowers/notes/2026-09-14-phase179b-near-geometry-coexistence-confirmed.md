## 判定

**近几何 Co-SR 共存: CONFIRMED（表征测量，非 A/B）**
- 干扰功率 0→31.5dB 全程受害者自身帧成功 678-921（升/降臂），无单调劣化、
  无膝点；满功率 31.5dB 配对均值 95.3% 为全场最高
- **几何增量被量化**：干扰耦合门限（B 帧首次抵达 A 的功率档）从远几何 16dB
  前移到近几何 8dB ≈ **+8dB 耦合增益**；B 帧到达数在满功率达 3311（远几何 2139）
- **受害机从未被夺走捕获**：B 帧在 A 处 DECODE_SUCCESS 恒 0（len89_contam
  全 12 点 0）——A 捕获自身信号，干扰帧只能进入候选但解不出
- **升臂 16dB 单点 5.7% 判为测量系统瞬态**（原写「环境瞬态」，经同日调试更正，
  见文末「更正 2026-09-14」）：三条证据——① 同功率降臂 96.8%；
  ② 升臂自身在更高功率 24dB(69.9%)/31.5dB(98.1%) 回升，"干扰越强越好"无物理
  机制；③ 该点逐窗口 6/6/6/20/5 均匀低达 75s，与真功率效应应有的单调形态不符
- DRIFT SUSPECT（预期内）：首尾 OFF 漂移 18.5pp——近几何窗间噪声 ±15pp
  （远几何 ±5pp，box2 机箱近场反射增加的额外多径），该噪声带即曲线分辨力上限
- 分子分母窗口：分母 est_sent~150/15s 窗 ×5 窗 = 750/点（interval 100ms，
  warmup 20s 已由 harness 排除）；分子 FCS_OK = [RESULT] per-window 计数器差值
  （P159b 分母同域规避）；len89 计数 = A 侧 stderr 全程 DECODE_SUCCESS len=89 行数
  （PSDU 89=B 帧，长度归因，P178 方法）

## 更正 2026-09-14（同日系统化调试后追加）

**被更正的原表述**：本文件原将升臂 16dB 单点 5.7% 与首次启动的 41.3% 崩塌
称为「**环境瞬态**」，并把后者根因定为「**设备刚上电 LO 未热稳**」。

**更正为**：两者都是**测量系统自身的瞬态**，与环境（外部干扰/信道）和设备
热状态均无关。上述根因表述系未经验证的推断，**撤回**。

**证据**（同日 P180 复现同类崩塌后做的组件级定位，全部基于日志计数）：

1. **发射侧完全正常**：健康臂与崩塌臂的 TX 链标签数一字不差
   （`TX_LSIG=2850`、`TX_HT_SIG=3800`、`TX_SCRAMBLER=1900`、`SIGNAL_GEN=2850`、
   `MAPPER=1`）——排除 TX 停摆/欠载
2. **`wifi_start` 标签 42×**：健康 969 → 崩塌 40673
3. **机制定位到具体代码路径**（`lib/ht_symbol_splitter_impl.cc:376-396`）：
   帧进行中收到新的 `wifi_start` 时，splitter 走 `force-transition` 分支
   **强制抛弃当前帧重启**。该路径在健康臂出现 **0** 次，崩塌臂 **37995** 次
   （占该臂全部 frame-start 的 93%）。真帧被反复抛弃 → 永远不完整 → 解码失败，
   同时 `FCS_FAIL` 恒 0（帧从未走到 FCS 校验）——这解释了本 phase 观察到的
   「到达率暴跌但 FCS_FAIL=0」矛盾
4. **崩塌臂处于 churn 状态**：stderr 93.9MB vs 同档正常静默臂 27MB（3.5×），
   splitter 空转（`[SPLITTER_LOOP] produced=0` 27 万次）

**已被证据排除的其它假设**（同日调试记录）：残留干扰进程/脏退出（崩塌臂
B帧@A=16，真干扰臂 782）、TX 欠载（TX 标签数相同；UHD 欠载标记恒 ~950/臂）、
CPU 热节流（满频 4.4-5.4GHz、无节流事件、load 0.4）、信号衰落（逐帧 SNR
波动 3-14dB 无单调趋势）。

**仍未确定**：触发该 churn 循环的条件（日志 I/O 争用为主假设，但证据不足——
单流图长跑 P181 写 337MB 零崩塌，与短臂的 I/O 速率相当）。

**连带更正——漂移对照点本身被污染**：本 phase 的 DRIFT 对照（首 OFF 91.7%
vs 末 OFF 73.2%，|Δ|=18.5pp）中，**末点 idx11 自身就带瞬态**：逐窗口
136/133/123/**96/61** 单调递减（对照几何的 P179 远几何末 OFF 点
116/125/109 是平的，该对照有效）。故 18.5pp 的「漂移」被瞬态放大，
真实谱间漂移小于此值。该对照是控制项、非结论依据，**不影响判定**。

**对本文档结论的影响**：**结论不变**。两个受影响的臂（首次启动臂、16dB 升臂）
本来就因预注册健康门与降臂对照被剔除，未进入任何结论数字。改动仅是把
「环境瞬态」的说法更正为「测量系统瞬态」。方法学副产品——逐窗口形态判别法
（单调递减 = 系统瞬态签名）——经此更正后仍然有效，但其解释从「热漂移」
改为「系统瞬态」。
