## 4. 方法论铁律（本项目沉淀）

1. **先根因后修复**；卡住时定位"瓶颈在哪一层"，不默认"又是均衡器"。
2. **门控统计量必须与证据统计量同点位**（P162b 教训）。
3. **离线回放正收益 ≠ 实时正收益**；实时配对 ABAB（p158_abab_batch.py）是金标准（P163 教训）。
4. **终点指标按机制作用层级选**：DS 被到达率噪声稀释时，用终败数/垃圾 L-SIG 等机制集中指标（P162 教训）。
5. **"物理墙"结论必须排除所有可修路径后才下**：P150"LO 墙不可破"是数据符号时代结论，L-SIG rot 候选覆盖（P165c）从未验证——一验证就救回帧（P165c 教训）。
6. **别把局部极限当替罪羊**（P159b/P163b 两次修正"环境/暂停"过早结论）。
7. 函数级 static 可变缓冲 = 跨实例竞争（P147）；consume_each=实际处理样本数（P151e）。
8. 真值计数与 est_sent 分母必须同时域（P160 伪影）。
