## 判定

**Co-SR 可行域（本几何）: 测量完成——可行域 = 自身功率裕度所划定的区域**
- **不可行点的成因是自身功率不足**：4 个不可行点全部含一条链路在 0 dB 增益
  （该链路自己只有 16.5-34%）。没有任何一点是"双方自身功率都充足、却因对方
  而双双失败"
- **同时发射的代价很小**：(31.5, 31.5) 时 A=91.8% vs 单人 85.3%，
  B=85.3% vs 单人 85.5%
- 分子分母窗口：分母 est_sent~150/15s 窗 ×4 窗 = 600/链路/点（interval 100ms，
  warmup 20s 已由 harness 排除）；分子 FCS_OK = [RESULT] per-window 计数器差值
- 可行性判据（预注册）：两条链路均 ≥ **50%**

### 两条副产品发现（对全 session 有回溯意义）

**1. 受害链路的自身最优工作点在 ~16 dB，不是 31.5 dB**

A 的自身链路 vs 自身功率（B 静默时）：
`0 dB ≈ 50% → 16 dB 94.3% → 31.5 dB 82.8%`

**31.5 dB 已过峰值**（近场自链路本来就强，再加满功率 → 接收端压缩）。
⚠️ **本 session 此前所有实验的受害方都固定在 31.5 dB**——相对比较仍成立
（条件一致），但绝对基线"~92%"是过驱动压过的值。

**2. 干扰效应再次呈非单调——满功率的邻居比中等功率更无害**

A=16 dB 行：`B=0 → A 94.3%`，`B=16 → A 77.3%`（最低），`B=31.5 → A 94.2%`。
A=0 dB 行同型（50.7 / 40.8 / 50.0）。
与 P182/P184 的"平台回升"第三次同型，持续指向**自适应检测阈值**机制。

## 机制与实现

- 新脚本 `p186_cosr_feasibility.py`：**两台设备并发运行正常自链路**
  （都收都发），每个网格点同时记录两条链路的成功率；单人基线用一台发射、
  另一台静默
- **与 P179-P184 的根本区别**：那些 phase 里 B 只是纯干扰源（且其自身链路
  在异常配置下从未解出任何帧）；本 phase 两台都是**真实工作的 BSS**

**实测前提**：先验证 B 的自链路在正常配置下可用（113/104/119 ≈ 75%），
确认"两个真实 BSS"存在——这排除了"B 链路本就不可用"的可能

## 决策

- **本几何下 Co-SR 无需功率协调**：可行域由各自的最低功率需求决定。
  这与 P179/P179b/P180 的"无效应"一致，但本 phase 首次以**联合可行域**的
  正确形式给出
- **若要观察 Co-SR 的"张力"（两路强度可比），必须改变几何**：当前每台设备
  自收自发，自身信号在自家接收机处压倒性占优。可选路径：第三方接收机
  （借用一台的 RX 子板并移动天线）、电缆 2×2 + 衰减器
- **后续实验的功率工作点应改为 A≈16 dB**（本 phase 实测最优）
- 无默认翻转、无新 env var、无禁止方向变更
