## Why USRP run failed

### Stage 1 result (60s @ 5250 MHz tx-gain 0 cable)

```
[TEST] Sent: 120
[TEST] Recv: 0
[TEST] Success Rate: 0.0%
[TEST] FCS_OK=0 FCS_FAIL=0

HT_SIG_CAND=16, all fail=crc_fail
```

This **reproduces the Phase 81 verdict** exactly: cable @ 5250 boosts avg_snr_lsig
(per Phase 81 +5.7 dB), but **zero frames decode end-to-end**.

### Stage 2 blocked — parser format mismatch

The capture script `examples/p80b_usrp_capture_for_lut.py` parser expects:

```
[HTSIG_INPUT_DUMP] frame=123 sym_idx=0 rx52=[...] H52=[...]
```

But the actual C++ output (per commit `8c6783f` chain) produces:

```
[HTSIG_INPUT_DUMP] inv_a=0 inv_b=0 enc96=<96 bits>
```

**No `rx52` or `H52` array is dumped.** The LUT builder (T7) needs equalizer
output values, but the dump site is at viterbi input — different point in the
chain. To fix:
- Either: add `rx52`/`H52` dump in `decode_htsig_from_rotated()` (post-equalize,
  pre-viterbi) gated by a new env var, e.g. `IEEE80211_HTSIG_EQ52_DUMP=1`.
- Or: dump from `frame_equalizer_impl::equalize()` directly via
  `IEEE80211_H52_DUMP=1` (already exists in chain, see Phase 78b).

### Stage 3/4 blocked — equalizer layer exhausted

Even if Stage 2 had produced a valid LUT, applying it at HT-SIG0/HT-SIG1 equalizer
output would face the **same viterbi wall** Phase 79 proved uncrossable:

- Phase 79: avg_snr_htsig 2.80 dB vs 6+ dB required → REFUTED
- Phase 80b baseline: HT_SIG_CAND=16/16 crc_fail → wall unchanged
- 20+ equalizer-layer hypotheses REFUTED (see MEMORY.md `禁止方向` section)

## Why realistic-synthetic LUT gate did not transfer

`examples/test_htsig_per_sc_cal_realistic_synth.py` (commit `8c6783f`) shows
**+1.336 dB SNR and 7/60 CRC-OK** with LUT on a USRP-physics-faithful synthetic
channel. This validates LUT **infrastructure** (no regression, magnitudes near
unity, Δ-correlated) but cannot reproduce what USRP shows because:

1. Synthetic rotating nulls vs USRP stable nulls (Phase 78b finding)
2. Synthetic has no UHD streaming instability / overflow losses
3. Synthetic L-SIG viterbi converges — USRP L-SIG viterbi fails before HT-SIG
   even gets a chance (crc_fail on HT-SIG means upstream was already broken)

The synthetic test **cannot bridge** USRP's upstream gates.
