## 判定

**占空比标度: CONFIRMED（表征测量）**
- **基线无漂移**：首静默臂 91.67%（139/137/134/140 均匀）；末静默臂均值 79.0%
  但逐窗 **61/132/139/142** = 起始降级后恢复，**后三窗 88-95% 与开头一致**。
  故全程基线 ≈ 92%
- **逐窗均匀性作为可用性判据**（P179b 建立的规则）：12 个噪声臂中 7 个均匀、
  5 个震荡/崩塌。按可用臂给出的曲线：

  ```
  92%（静默）→ 76%（6dB）→ 77%（12dB）→ 79%（18dB）→ 80%（24dB）→ 91%（31.5dB）
  ```

  **形态：先跌 ~16pp 至最低点（6-12 dB），随后单调回升至接近基线**
- 逐档两趟一致性：6dB **3.5pp** ✓ / 12dB **1.5pp** ✓ / 24dB **7.0pp** ✓ /
  18dB 23.3pp ✗ / 31.5dB 64.8pp ✗ / 0dB 31.0pp ✗
- 分子分母窗口：分母 est_sent~150/15s 窗 ×4 窗 = 600/臂（interval 100ms，
  warmup 20s 已由 harness 排除）；分子 FCS_OK = [RESULT] per-window 计数器差值

### 干扰机的发射可靠性（Step A，本 phase 先做的前置验证）

用 **B 自身 TX 链的计数**（`b_tx_lsig`，独立于受害机状态）验证：

- 同增益下 4 次重复：32064 / 35436 / 32166 / 32190 → **CV 4.5%**，发射可靠
- 全程 12 臂多数落在 31-35k 簇，**偶发偏低**（15954、22266）——对应那些臂
  B 实际发射时长偏短，其名义功率档低估了真实投送量
- ⚠️ **这条指标（B 自 TX 计数）是必要的**：受害机日志里的 `len=1028`
  （B 帧到达数）**不能**用来判断"B 发没发"——受害机自身崩溃时同样收不到，
  两者混淆正是 P183 误判的根源

**受害帧被击中概率**：帧长 1.30ms / 周期 10ms，受害帧 0.12ms/100ms
→ 命中率 ≈ (0.12+1.30)/10 = **14.2%**

## 对 P183 的两条更正

**1. 「B 的发射量本身不可控（差 29 倍）」——错误，撤回。**
那 29 倍是**受害机日志中解出的** B 帧数（`len=1028`），它同时受 B 发射与
**受害机接收状态**影响。本 phase 用 B 自身 TX 计数验证：**发射侧 CV 仅 4.5%**。
**P183 观测到的波动来自受害接收机，不是干扰源。**

**2. 「26% 占空比超出 harness TX 链能力」——无证据，撤回。**
本 phase 在 13% 占空比下同样偶发偏离（16k/22k），说明偏离与占空比不是简单因果。

## 机制与实现

- `p182_ota_noise_sweep.py` 的 `--b-frames` 模式（B 走正常帧发射链，只调
  `--b-len/--b-interval` 提高占空比，**零 harness 代码改动**）
- 本 phase 新增：**B 自身发射量的摘取**——在删除 B 的大日志（~1.3 GB/臂）前，
  用 grep 提取 `b_self_len1028 / b_self_any_ok / b_tx_lsig / b_tx_htsig` 四个计数
  存为小文件。这是判断"干扰源是否在发"的唯一独立指标
- 帧长计算（MCS0，26 dbps）：PSDU 1028B → 318 符号 → 1.27ms + 前导 ≈ **1.30 ms**

**机制推断（未直接验证）**：「干扰越强反而越好」的回升段与 P182 的平台回升同型，
最可能的解释是 **sync_short 自适应阈值**——干扰抬高尾随窗口 p90 → 阈值抬高 →
误触发减少 → 链路恢复。**干扰的净效应 = 抬高底噪（坏）与抬高检测阈值（好）的竞争**，
在低占空比下后者占优。该机制本 phase 未做直接验证（需 dump 阈值轨迹）。

## 决策

- **13% 占空比是本实验床的可用工作点**：效应可测（−16pp）且部分可复现，
  残余的双稳用"逐窗均匀性"判据剔除即可
- **Co-SR 功率协商的可用结论**：干扰的时间占空比是决定量。0.12% 无害、
  13% 轻微、100% 灾难。**因此"邻区 AP 的发射功率"单独不构成协商依据，
  必须连同其帧的时间结构一起考虑**
- 仍不建议在 OTA 上追求单值门限（双稳未消除）；若要精确门限，转电缆 2×2
- 无默认翻转、无新 env var、无禁止方向变更
