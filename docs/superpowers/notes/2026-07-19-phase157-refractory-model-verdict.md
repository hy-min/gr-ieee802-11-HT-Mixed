# Phase 157: Gap 0.3 回退根因 — 不应期模型确认

**日期：** 2026-07-19
**状态：** ✅ **CONFIRMED** — 截断模型 REFUTED（电缆），不应期模型
CONFIRMED（空口直接签名：连环重触发 10→218，22×）

---

## 背景

Phase 155：空口 gap POWER_THRESHOLD 0.01→0.3 回退（batch mean 200→102.5），
当时归因"真帧被截断"未验证。**ultrathink 重审**：真帧内 RF 功率持续
（均值 3-28），500 连续低于 0.3 的样本在帧内不可能 → 截断解释自相矛盾。

## 竞争假设与判别实验

- **截断模型**：0.3 在帧中触发 gap → decode 尝试应少于 HT-SIG OK。
- **不应期模型（假设 C）**：0.01 的长 COPY episode 是保护性不应期 ——
  噪声突发触发假检测后 ~6ms COPY 抑制连环重触发；0.3 拆除不应期 →
  噪声突发机关枪式重触发 → 假 wifi_start 标签轰炸 → L-SIG 链污染
  （Phase 153/154 已证假标签是 L-SIG 垃圾主因）。

## 电缆实证（SMA 直连 g25，单变量 gap 阈值）— 截断 REFUTED

| 指标 | 电缆+0.01 | 电缆+0.3 |
|---|---|---|
| DECODE_SUCCESS | 234 | 246（无回退） |
| good L-SIG | 274 | 275 |
| HT-SIG OK | 256 | 263 |
| decode 尝试 | 256 | 263（**= HT-SIG OK，零截断**） |
| 检测数 | 581 | 599 |

电缆（突发少）上 0.3 完全无害 → 空口回退是**噪声介导**的。

## 空口确认（背靠背，M=24，rx-gain 31.5）— 不应期 CONFIRMED

| 指标 | air+0.01 | air+0.3 |
|---|---|---|
| **连环重触发（<5k 间隔）** | **10** | **218（22× 爆炸）** |
| COPY 占用 | 13.7% | 1.5%（不应期拆除） |
| 总检测数 | 1333 | 1188 |
| good L-SIG | 203 | 176（-13%） |
| HT-SIG OK | 194 | 174 |
| DECODE_SUCCESS | 187 | 161（-14%） |

0.3 拆除不应期 → 噪声突发连环重触发 22× → 假标签轰炸 → L-SIG/FCS
下降。直接签名命中。

## 结论

1. **0.01 承重的真正原因 = refractory period**（抗噪声突发），不是
   "正确的功率电平"。Phase 155 REFUTED 现在有根因解释。
2. **残余 20% COPY 捕获的正确攻法 = "不应期但不瞎"**：保留噪声重触发
   抑制，同时让 COPY 态对明显更强的真 L-STF 平台（如相关 >10× 门限）
   重新触发。不能缩短 episode。
3. 工具：`IEEE80211_SYNC_SHORT_GAP_POWER_THRESHOLD`（opt-in，
   默认 0.01 保基线），实验免重编译。
