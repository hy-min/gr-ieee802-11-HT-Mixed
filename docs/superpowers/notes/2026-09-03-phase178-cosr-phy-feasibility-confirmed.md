## 判定

**Co-SR PHY 层可行性（gr-ieee802-11 实验床）: CONFIRMED（有条件）**
- 捕获效应存在：τ=0 强 ≥3dB 帧可解（A 侧 +3dB→68%，B 侧 -3dB→42%）
- 可行域量化（MCS 0）：受害链路需自信号 ≥ 干扰 **+3dB**
- **架构限制（重要）**：单接收机永不双帧同解（输家恒 0）——串行单用户解码器，
  无多用户检测/SIC。Co-SR 真实形态（每个 STA 各自解码自己的 AP）不受影响。
- **时序硬约束**：晚到帧必死、无间隔接续帧不可见、26-76µs 间隔撞解码忙窗
  → Co-SR 必须同时开始（invite/resp 协商的存在意义；需要确定性帧同步 =
  CD-2520 共基 + P172b timed-burst）。
- 分子分母窗口：分母 = 每配置文件 50 帧对（全部覆盖，回放为 CPU 全速无
  warmup 分母伪影问题——文件首 100ms 纯噪声前缀吸收 sync warmup）；
  分子 = 该 len 的 DECODE_SUCCESS 计数（A=len66, B=len89，len 归属无混淆）。

## 机制与实现

- 管线 `p178_cosr_mix.py`（本 commit）：从 --tx-capture 波形按自相关帧周期
  （2481/3041 样本）提取单帧 → numpy 按 SIR×τ 混合 + 噪声床（RMS 0.0186，
  p150 实测）+ 100ms warmup 前缀 → e2e hier RX 回放 → 按 len 归属计数。
- **仪器选择教训**：harness `--rx-file` 路径（P171 已证伪的 file 实验床）对
  合成流 L-SIG 全崩（H_mag 随机、avg_snr=3.16）；e2e hier RX 回放
  （test_file_replay_e2e.py，P145c 验证路径）23/23 正确。**P171 结论再次有效。**
- **sync 阈值需要真实噪声床**：纯零间隙下 sync 触发定时漂移（L-SIG 垃圾），
  加 RMS 0.0186 噪声床后恢复正常——合成流制作要点。
- 固定位相是伪影源：混合两路确定内容 + 固定 τ → 相位关系恒定 → τ=0 中 SIR
  区假凹陷；每重复随机相位旋转消除。

### 阶段 1 空口链路改进（2026-09-09）：H52_2WAY 跨设备空口 MCS 0 CONFIRMED +8.7pp

**背景**：跨设备空口链路（box2→box1，5890，A槽 TX/RX 发 + B槽 RX2 收，1m）
基线 61-74%（高时变）。曾误判"衰落主导、软件无解"——本 ABAB 证伪该论断。

配对 ABAB（跨设备空口 MCS 0 len38，臂 A=现状 / 臂 B=+IEEE80211_H52_2WAY_DEFAULT=1，
4 对交错，governor=performance，freq 5890，tx/rx-gain 31.5，tx-scale 1.0，
两臂 HDR_COMP_DISABLE=0 + SYNC_LONG_XCORR_FS=1）：

**信道剧烈漂移**（两臂首轮 ~9% → 末轮 ~40%，摆动 23-28pp，漂移告警触发）；
配对交错设计保护了对照（每对相邻同测），效应量 +8.7pp 可信；绝对电平仅本批次有效。

**机制统一（与 P177 MCS1 NOT CONFIRMED 互补，非矛盾）**：

| Regime | 瓶颈 | H52_2WAY |
|--------|------|----------|
| MCS 1 pad 对齐（P177 跨设备电缆）| 数据符号逐符号相位噪声（随机游走）| NOT CONFIRMED（H 层触及不到符号维噪声）|
| MCS 0 空口（本次）| 衰落期 L-LTF H 估计噪声（BPSK 抗相位噪声，但衰落压 SNR → H 差 → 均衡差 → 比特错）| **CONFIRMED +8.7pp** |

**结论**：2way 只在"H 估计质量是瓶颈"时有效（衰落/边际 SNR），对"数据符号
自身相位噪声"（MCS 1 pad 场景）无效——作用域划分由此精确化。空口链路有软件
headroom，非死墙。
